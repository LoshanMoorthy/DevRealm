# DevRealm

**DevRealm** is a developer knowledge hub that connects your snippets, tags, and related resources. It provides an intuitive graph-based visualization, making it easy to organize, explore, and share code snippets in various programming languages.

## Features

- **Graph View**: Visualize the relationships between your snippets and tags.
- **Snippet Management**: Add, edit, and manage code snippets with support for markdown and syntax highlighting.
- **Tags**: Organize snippets by tags for easy searching and filtering.
- **AI-powered Explanation**: Request AI-generated explanations for your code snippets.

## Technologies Used

- **Frontend**: 
  - React.js
  - Chakra UI
  - React Force Graph
- **Backend**:
  - C# with ASP.NET Core
  - SQLite database
- **AI Integration**: 
  - Local AI integration using Ollama for code explanation.
